Additional retained diagnostics:

- `stations/Pick_snow_year.ipynb` reproduces the low/typical/high-year selection.
- `watershed/Watershed_comparison.ipynb` is the earlier source reference. It
  lacks the final ASO markers. `plot_watershed.py` restores them from the
  author's `aso_watershed_observations_raw_native.csv` and reproduces all 18
  rows of the author's final watershed-statistics CSV within 1e-9. The
  native-ASO aggregation itself is supplied as saved data, not regenerated by
  this plotting driver.
- `stations/Point_Comp_timing.ipynb` exports station dates and signed differences
  used by main Table 3 and supplementary Table S2.
- Main Table 2 and Table S1 use paired station SWE bias statistics; the station
  comparison notebooks and upstream annual station table supply these values.
- `aso/ASO_metrics_with_bulk_density.ipynb` supplies the common-grid spatial
  SWE/depth/density metrics underlying main Table 4 and Tables S3–S4. It rebuilds
  unfiltered ASO inputs before calculation. See `MANUSCRIPT_CORRECTIONS.md` for
  corrections to earlier values based on filtered archived inputs.
- `aso/ASO_iSnobal_density_grid_scale_diagnostic.ipynb` inspects density and
  aggregation order; its spatial supports should not be conflated with S9.
- `wy2026/East_River_Noah_iSnobal_FSNO_2panel_WY2026_vs_2018_2025_v0.2.0.py`
  retains the distinct FSNO-bin ablation/event-count diagnostic. It is not one
  of the 21 figures referenced in v4. WY2026 curves are compared with the
  prior-year median and IQR; that envelope is interannual spread, not a
  confidence interval.
- Main Table 1 is a descriptive configuration comparison, not a calculated
  statistical table.

The older `ASO_metrics.ipynb` is redundant with the metric calculations in
`ASO_metrics_with_bulk_density.ipynb`. The old MODIS v0.1.3/v0.1.4 and energy
v0.3.0 alternatives are not offered as competing reproduction entry points.
